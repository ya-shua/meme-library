# 表情包收录库 · meme-library

一个独立的本地表情包管理器：浏览远程资源库 → 预览 → 下载入库 → 分类打标 → 两档审核 → 聊天时自动配图。

不是某个框架的插件，是自带 aiohttp 大厅的独立模块：宿主只要在启动时调一下 `main.py` 的 `setup()`，就能拿到一套完整的表情包服务；单独跑大厅也能用。

核心理念两条：

- **大厅是预览态**，看着合适再下载入库，不贴个地址就往本地灌图
- **预览用缩略图，下载永远拿原图**

## 特性

- **资源广场**：20 条预置地址，全部中文口径，卡片 5 等分，点「下载」直接入队下载，点「预览」先看再决定
- **预览加速**：服务端生成 420px 缩略图并落盘缓存，首次几秒，第二次 0 秒；没装 Pillow 自动退回原图
- **可控下载**：居中弹窗显示进度，可取消、可切后台；任务状态落库，刷新页面、重启宿主都能接回来
- **下载记录**：进行中 / 已完成 / 已取消 / 失败都在「下载」页，单条可删、可清空
- **集合隔离**：每个包在 `memes/` 下是同级目录，物理隔离，可单独启用或禁用
- **两档审核**：AI 高置信进「待确认」，低置信进「待审核」，都能单张确认、整档入库、一键撤回
- **回收站**：删图先进回收站，50 张上限，随时复原，标签和审核状态一起保留
- **梗图独立**：`meme` 类型不参与自动配图，只能手动发
- **心情映射**：本地静态表，不耗 token，命中不到就兜底到最接近的分类


## 安装

```bash
pip install aiohttp
pip install pillow        # 可选，装了预览才走缩略图
```

`requirements.txt` 里 aiohttp 必装，Pillow 可选；大厅设置页也提供一键安装。

宿主挂载方式：把目录放到宿主的插件扫描路径下，或者直接 `import main` 后调用

```python
await main.setup(services, config)   # services 里放 stickers / llm 之类
```

## 配置

```json
{
  "hall_host": "127.0.0.1",
  "hall_port": 7802,
  "inject_prompt": true,
  "vision": { "base_url": "", "api_key": "", "model": "", "timeout_s": 60 },
  "preview": { "github_token": "" }
}
```

| 键 | 说明 |
|---|---|
| `hall_host` / `hall_port` | 大厅监听地址，默认 `127.0.0.1:7802` |
| `inject_prompt` | 是否往系统提示里注入可用分类，引导模型按心情发图 |
| `vision` | AI 打标用的视觉模型，留空则 AI 打标不可用，本地推断照常 |
| `preview.github_token` | 可选。填了能突破未登录 60 次/小时的接口限流 |

## 大厅

浏览器开 `http://127.0.0.1:7802`，左侧导航七项。

### 概览

四张统计卡（总数 / 已确认可用 / 待过一眼 / 未分类）、七类分布条、包列表。分布只算「已启用 + 已确认」的图，也就是聊天真能抽到的那些。

### 资源广场

一个网格放全部地址，不分「推荐 / 精选」。每张卡：封面（真图）、名称、说明、两个淡色按钮。

- **下载**：直接入队，弹窗显示进度，可取消可后台。下载走 zip 直下，不吃 GitHub 接口额度
- **预览**：先看仓库里有什么，进详情浮层翻页，满意再回来下载；已入库的卡片直接给「打开看」

页头右侧可以贴任意仓库地址，先判断是不是表情包仓库：不像的只给一句提示，末尾留一个「仍然预览」硬看。判定条件：有包内索引且不少于 5 张；或命中 2 个以上分类目录；或核心图 ≥ 12 张且占比 30% 以上；或总图 ≥ 100。

### 我的表情包

和资源广场一致的卡片网格，每张卡：封面、包名、张数、`预览` / `启用|禁用` / `删除`。

- 页头显示「共 N 个包」和「N 个启用」
- 右上角勾选框，可以多选，页头出现「已选 N」和「删除选中」
- 启用中显示黄色「禁用」，未启用显示绿色「启用」
- 点「预览」进包内页浮层：左列分类、右边图片网格，支持多选、批量加标签 / 改标签 / 删图

### 下载

所有下载任务的历史：进行中、已完成、已取消、失败。

- 进行中带「看进度」，点开把下载弹窗拉回来
- 已完成带「打开这个包」，直接跳包内页
- 已结束的记录可以「删掉」单条，也可以「清空记录」；正在跑的不让删

### 回收站

删掉的图先来这里，最多 50 张，超出按最旧自动清。图片能看、能单张复原、能批量复原、能彻底删除。包名、标签、审核状态都跟着保留，复原后不用重新打标。

### 审核中心

左右两栏：左「高置信待确认」，右「待审核」。单张可入库或撤回，也能整档一键入库。右上角两个按钮：本地规则打标（0 token）、AI 识别（要配 `vision.model`）。

### 设置

心情词到标准分类的映射、内置词列表、自动配图链路图，以及「预览加速」面板（Pillow 状态、一键安装、缓存上限）。

## 下载与预览的实现取舍

**预览取清单三步走**，因为 GitHub 接口没登录一小时只给 60 次：

1. 已入库的包直接读本地库，一张图都不联网
2. 没入库但 ≤ 50MB 用 jsDelivr 的文件树接口，1~2 秒拿全量清单
3. 没入库又 > 50MB 才动 GitHub 接口，一个包只发一次

清单落盘缓存 24 小时，反复预览、翻页、切分类都不重复烧额度。

**缩略图**：装了 Pillow 就按 420px 长边、质量 82 生成 JPEG 落盘，动图取首帧，透明转白底；没装就逐字节转发原图。缓存按 mtime 清，默认 128MB 上限。

**下载**：优先 codeload 的 zip，失败再 git clone。zip 会把压缩包流式写盘（不整块进内存），解压后只收 `memes/` 下的真图，跳过 `previews/`、`docs/`、`assets/` 这类封面拼图目录。中断时清临时目录、半截 zip 和已建的空包。

## 数据与清理

| 数据 | 位置 | 策略 |
|---|---|---|
| 数据库 | `data/meme_library.db` | WAL，含包 / 图 / 回收站 / 下载记录 |
| 预览清单缓存 | `data/preview_cache/` | 24 小时过期 |
| 缩略图 | `data/thumb_cache/` | 默认 128MB 上限，按 mtime 清 |
| 临时下载 | `data/temp/` | 任务结束或取消即清 |
| 回收站文件 | `data/trash/` | 最多 50 张 |
| 下载记录 | 数据库 `downloads` 表 | 最多 100 条 |

## 自动配图链路

模型按心情输出单行「【表情包：分类】」→ 宿主调 `services["stickers"]` → `StickerBridge` 把 hint 解析成标准标签（标准 tag → 心情映射 → 别名推断）→ 从启用集合的已确认图里随机取图发送；本图库没图时回退宿主内置图。

## 常见问题

- **没图可发**：只有「已确认」的图会被自动配图选中。下载后先跑「本地规则打标」，再手动补标签，或配好 `vision.model` 跑 AI
- **下载很慢**：境外源常被限速到 0.1~0.2 MB/s，几百 MB 的包要等十几分钟，弹窗会显示已下多少 MB
- **预览全是「加载失败」**：先确认能不能解析 jsDelivr 节点。换网络或者挂代理再试
- **点了预览没反应**：清一次浏览器缓存（Ctrl+Shift+R）；静态文件每次请求都读盘，改前端不用重启
- **同名的包已存在**：先在「我的表情包」删掉旧的，再重新下载
- **想要断点续传**：源站不支持 Range，做不到，只有取消重来

## 已知限制

- 没有「暂停下载」，原因同上：源站不支持 Range，续不回来
- 未登录时 GitHub 接口 60 次/小时，超大包预览可能被限流
- 整包删除不进回收站，只有删单张图才进
